# Auditorías

Reportes de análisis hechos por el analista (Gemini) y revisados por el mantenedor.
Cada reporte vive en `docs/audits/<tema>.md` y sigue el formato de `docs/equipo.md`
(severidad, evidencia `archivo:línea`, qué no se verificó). Nada en esta carpeta se
considera merge-blocking por sí solo: el mantenedor valida cada hallazgo contra el
código antes de actuar.
