# Specs de diseño (L1)

Toda pieza no trivial empieza acá: una spec por tema (`<tema>.md`) con problema,
no-objetivos, interfaz propuesta, invariantes, archivos tocados/no tocados, tests
esperados y riesgo residual. DeepSeek implementa; Claude aprueba revisión y merge;
el dueño puede vetar cualquier spec antes del código.

Formato mínimo de una spec: ver `docs/design/d1-bash-parser-tests.md`.
